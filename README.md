# Crystal Kizor

Single-page Next.js landing for the Crystal Kizor personal brand.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Brand portraits, project photography, and the Crystal Kizor logo live in `public/brand`. Original uploads remain in `public/Crystal_s pictures` and `public/Other assets`.

The enquiry form validates and logs submissions in the server console. Connect email or a CRM when you have an endpoint.
